# BoxKit — 3D-printable under-desk cable box

A screw-mounted under-desk enclosure (16 × 6 × 3-inch interior) that hides a USB-C
charger, a Mac mini and all the cable mess behind three fluted, tool-free removable
doors. 8 printed parts, every one fits a 200×200 mm bed, ~440 g of PLA total.

**▶ Interactive demo:** open `index.html` (or the GitHub Pages link) — 360° orbit,
X-ray view, 15 detail renders.

**⬇ Print package:** `files/boxkit_print_package.zip` — 10 STLs incl. two ready
print plates. Print settings are on the demo page (PLA, 0.2 mm, 15-20% infill,
segments upright / doors face-down, zero supports).

**⬇ Blender source:** `files/deskbox_source.blend` — fully parametric; every
dimension regenerates the parts.
